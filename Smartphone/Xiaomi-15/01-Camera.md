## Pro Mode Controls

| Control | Range |
|---------|-------|
| ISO | 50–3200 (or auto) |
| Shutter | 1/4000s – **30s** |
| White Balance | Auto / Presets / Custom Kelvin |
| Focus | AF-C / AF-S / **Manual + focus peaking** |
| Exposure | ±3 EV |
| Format | JPEG / **RAW (DNG)** |

### Pro Tricks
1. **Focus Peaking** — red/green edge highlights for manual focus
2. **Zebra Stripes** — overexposure warning overlay
3. **Histogram** — live RGB exposure meter
4. **Gyro Level** — horizon line from gyroscope
5. **2x Crop** — sensor-based 2x from main, very sharp
