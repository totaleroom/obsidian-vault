# Xiaomi 15 Performance Optimization

---

## ⚡ Highest-Impact: Animation Scales

**Path:** `Settings → Additional Settings → Developer Options`
> 7x tap MIUI/HyperOS version to unlock

| Setting | Default | Speed Demon |
|---------|---------|------------|
| **Window animation scale** | 1.0x | **0.5x** |
| **Transition animation scale** | 1.0x | **0.5x** |
| **Animator duration scale** | 1.0x | **0.5x** |

**0.5x = cuts animation time in half** — single highest-impact tweak.

---

## Memory Extension (Virtual RAM)

**Path:** `Settings → Additional Settings → Memory Extension`

| Physical RAM | Options | Default |
|-------------|---------|---------|
| 12GB (Xiaomi 15) | +3GB / +5GB / **+6GB** | +6GB (HyperOS 2) |

Best for multitasking — keeps more apps in memory.

---

## Background Process Limit

**Developer Options → Background process limit → At most 4 processes**

Good balance on 12GB RAM — restricts background apps without breaking notifications.

---

## Game Turbo (HyperOS 2)

**Path:** `Settings → Additional Settings → Game Turbo`

### Ultimate Mode (New)
- Lifts CPU/GPU to maximum
- Lifts thermal throttling limits
- **→ Use for Genshin, PUBG Mobile 120fps**

### PUBG Mobile 120fps
1. Open **Game Turbo** → activate
2. Set Graphics: **Smooth + Extreme**
3. Restart game
